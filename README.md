## stormCast implementation for Singapore

This is a summer intern project that implements the stormCast model for Singapore domain, using SING-V3 data for training and testing. 
The work is carried out in the CCRS Core Modelling Development branch by Aditya Jayaraj, an undergraduate student from NUS, under the supervision of Chanh Kieu, CCRS/CMD.
All questions or inquiries can be sent to chanh_kieu@nea.gov.sg.
